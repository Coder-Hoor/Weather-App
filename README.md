# 🌤️ Weather App

A simple and responsive weather application built with **HTML, CSS, and JavaScript**.
The app allows users to search for a city and view its current weather information.

## ✨ Features

* 🔍 Search for weather by city name
* 🌡️ Display current temperature
* ☁️ Show current weather condition
* 💧 Display humidity
* 💨 Display wind speed
* 🌅 Dynamic weather icons
* 📱 Responsive design for different screen sizes
* ⚡ Fetch real-time weather data from a weather API
* ⌨️ Press **Enter** to search for a city

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and responsive design
* **JavaScript (ES6+)** — Application logic and API handling
* **Weather API** — Fetching real-time weather data
* **Git & GitHub** — Version control

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Coder-Hoor/Weather-App.git
```

2. Open the project folder:

```bash
cd Weather-App
```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.

## 🔑 API Configuration

This project uses a weather API to retrieve real-time weather information.

If you are running your own copy of the project, make sure to add your own API key in the JavaScript file.

**Important:** Never upload a private API key to a public GitHub repository.

A safer approach is to keep your API key in an environment variable or another file excluded through `.gitignore`.
